# Configurable Columns — Guide

## Column Name Input (Sprint Creation)

Each sprint has three reflection columns where participants write observations, plus one fixed Action Items column for commitments. You can name the three reflection columns to match your preferred retro format. Popular combinations include "Went Well / Didn't Go Well / Start Doing" (default), "Start / Stop / Continue", "Glad / Sad / Mad", and "Liked / Lacked / Learned". Names can be up to 30 characters. If you've run a previous sprint, the names from your last retro are pre-filled so you don't have to re-enter them each time.

## Column Color Picker (Sprint Creation)

Colors help participants quickly identify which column they're looking at, especially on mobile where only one column is visible at a time. Choose from 8 preset colors: green, red, amber, blue, purple, teal, pink, and slate. The defaults (green for column 1, red for column 2, amber for column 3) work well for most formats, but you can change them to match your team's preferences. Multiple columns can share the same color if you prefer.

## Column Header (Sprint Board — SM)

As the Scrum Master, you can rename columns or change their colors at any point during the retro — even after participants have started writing cards. Click any reflection column header to edit it. Cards stay in their column regardless of name changes, so renaming is always safe. Changes are pushed to all participants instantly. Use this if your team decides mid-retro that a column name isn't working or if you want to clarify what belongs in a column.

## Column Header (Sprint Board — Participant)

Column headers show the names your Scrum Master chose for this retro. These names tell you what kind of observation belongs in each column. If a header changes during the retro, the SM is adjusting the format — your existing cards stay where they are.

## Third Column (Sprint Board)

The third reflection column is new in this version. It gives your team space for a third category of observations. In the default format, it's "Start Doing" — a place for new ideas and practices the team hasn't tried yet. Your Scrum Master may name it differently depending on the retro format. It works exactly like the other two reflection columns: you can write cards, group them, and vote on them.

## Action Items Column Fixed Label

The Action Items column is structurally different from reflection columns. It holds commitments (who will do what), not observations. That's why its name ("Action Items") and color (blue) are fixed — it signals to participants that cards here are assignments with owners, not open-ended reflections. Only the Scrum Master can create action items, and they require an assignee name.

## Pre-filled Column Names (Sprint Creation)

When you create a new sprint, the column name and color fields start with the values from your team's most recent sprint. This saves time when your team uses the same retro format repeatedly. If you're switching to a new format, just overwrite the pre-filled values. If this is your team's first sprint, system defaults are used (Went Well / Didn't Go Well / Start Doing in green / red / amber).
