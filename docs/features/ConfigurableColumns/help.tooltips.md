# Configurable Columns — Tooltips

## Column Name Input (Sprint Creation)

Name this column (max 30 characters). Cards created here will appear under this heading.

## Column Color Picker (Sprint Creation)

Choose a color theme for this column. Helps participants visually distinguish columns at a glance.

## Column Header (Sprint Board — SM)

Click to rename this column or change its color. Changes appear instantly for all participants.

## Column Header (Sprint Board — Participant)

Cards in this column are grouped under the name your Scrum Master chose for this retro.

## Third Column (Sprint Board)

A third reflection column for observations that don't fit the first two. Your SM named it based on the retro format.

## Action Items Column Fixed Label

The Action Items column always keeps its name and blue color to distinguish commitments from observations.

## Pre-filled Column Names (Sprint Creation)

Column names are carried over from your team's last sprint. Change them if you're trying a different retro format.
