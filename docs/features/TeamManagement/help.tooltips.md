# Team Management — Tooltips

Tooltip text for UI elements. Each tooltip is shown on info icon hover. Max 150 characters.

---

## Team Dashboard

### Team Card — Sprint Count
The total number of sprints created under this team, including draft, active, and closed.

### Team Card — Last Sprint Date
The date when the most recent sprint was created in this team.

### Create Team Button
Create a new team. You can manage up to 10 teams.

### Create Team Button (Disabled)
You've reached the maximum of 10 teams. Delete a team to create a new one.

### Team Card — Three-Dot Menu
Manage this team. Options include deleting the team.

## Create Team Form

### Team Name Input
Choose a name for your team. Must be unique among your teams. Max 100 characters.

## Delete Team Dialog

### Confirmation Name Input
Type the team name exactly as shown above to confirm deletion.

### Delete Button (Disabled — Active Sprint)
This team has an active sprint. Close or delete it before deleting the team.
