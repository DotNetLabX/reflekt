# Timer per Phase — Tooltips

Tooltip text for UI elements. Each tooltip is shown on info icon hover, max 150 characters.

---

## Timer Display

Shows the countdown for this phase. Visible to everyone. The Scrum Master controls the timer.

## Start Timer

Start a countdown for this phase using the configured default duration. Only the Scrum Master can start.

## Pause / Resume

Pause the countdown to hold the clock. Click again to resume from where it stopped.

## Reset Timer

Reset the timer to the phase's default duration. The timer won't start until you click start again.

## Add Time (+1 / +2 / +5)

Add extra minutes to the timer. Works while running, paused, or expired. If expired, it resumes the countdown.

## Mute Toggle

Mute or unmute the timer expiry sound on your device. This only affects you, not other participants.

## Timer Expired Alert

Time is up. The board stays open — you can keep working. The Scrum Master decides when to move on.

## Timer Duration Defaults (Sprint Creation)

Set how long each phase timer runs by default. You can adjust mid-retro with +time or reset.
