# Inline Phase Controls — Tooltips

Tooltip text for UI elements. Each tooltip is shown on info icon hover, max 150 characters.

---

## Next Phase Button

Advance the retro to the next phase. Only the Scrum Master can advance. This cannot be undone.

## Close Sprint Button

End this retro and lock all changes. The board stays visible in read-only mode for everyone.

## Phase Stepper

Shows the retro's five phases: Writing, Grouping, Voting, Discussing, Reporting. The active phase is highlighted.

## I'm Done Button

Let your team know you're finished with this phase. Click again if you change your mind.

## Readiness Badge

Shows how many participants have signaled they're done with this phase. Informational only — it won't block the Scrum Master.

## Voting Warning (Advance Dialog)

Some participants may not have voted yet. The Scrum Master can still advance — this is a heads-up, not a blocker.

## Discussion Gate (Advance Dialog)

At least 2 groups must be discussed before moving to Reporting. Discuss more groups or toggle existing ones.

## Sprint Closed Notification

The Scrum Master has closed this retro. The board is now read-only. You can still view the report and copy it.
