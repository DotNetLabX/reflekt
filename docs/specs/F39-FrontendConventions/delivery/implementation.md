## Step 8 — Optimistic actions in the stores
**Files:** `web/reflekt-web/src/stores/pendingValues.ts` — new store-private helper `createPendingValues(apply)`: optimistic changes to one absolute value per key, oldest first. `change` applies and records `{ prev, next }`. `settle(key)` / `settleAll()` drop the record when an authoritative payload replaced the value. `confirm` settles the change and every older one, and hands the server's value to a newer change as its base, else applies it. `undo` undoes only an unsettled change: it restores `prev` when it is the newest, or hands `prev` to the newer change, so a value on screen from a newer request is never overwritten (Decision 16). `web/reflekt-web/src/stores/card.ts` — **create:** a temporary card (negative id, the current participant, the payload) is unshifted at once.
