# Backend code vs pattern skills (repo: the F33 worktree)

Method: read the 11 skills (SKILL.md + workflows), then read every file under `Reflekt.API/Features/**` (44 endpoints, 21 handlers), `Reflekt.Domain` (7 aggregates), `Reflekt.Persistence` (9 configs, 8 repos, DI), `src/BuildingBlocks/**` (4 projects), plus `Auth/`, `Middleware/`, `Mappings/`, `Hubs/SprintHub.cs`, `DependencyInjection.cs`. Counts below come from grep over `src/Services/Reflekt`. Nothing was executed; "behavior risk" = what could change for callers if the fix is applied.
Paths are relative to `src/Services/Reflekt/` unless they start with `src/BuildingBlocks/` or `web/`.
