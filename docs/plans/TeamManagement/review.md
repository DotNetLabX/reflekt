## Cycle 1 Findings (all resolved)

### [HIGH — RESOLVED] Migration Down() will fail in SQLite
**Fix applied:** `Down()` rewritten with raw SQL using the same table-rebuild pattern as `Up()`. Correct ordering: drop composite index → rebuild `Teams` without OwnerId (restoring `CreatorEmail` as empty placeholder) → restore `IX_Teams_CreatorEmail` index → drop `Users`. The destructive data-loss is documented with an explicit comment. FK ordering is now correct: `Teams` rebuilt (FK removed) before `Users` dropped.

### [HIGH — RESOLVED] `DeleteTeamWithCascadeAsync` not atomic
**Fix applied:** `await using var tx = await Db.Database.BeginTransactionAsync(ct)` wraps the entire method; `await tx.CommitAsync(ct)` at the end. All seven `ExecuteDeleteAsync` calls now execute within a single SQLite transaction.

### [HIGH — RESOLVED] `UserConfiguration` missing NOCASE collation on Email
**Fix applied (two-part):** `UserConfiguration.cs:12` now uses `.UseCollation("NOCASE")` on the Email property. A separate migration `20260509220316_AddUserEmailNocaseCollation` was generated by EF to apply `AlterColumn` with `collation: "NOCASE"` to the existing `Users.Email` column, with a correct `Down()` that reverts it. Both Up() and Down() are clean.

### [MEDIUM — RESOLVED] Migration COALESCE(OwnerId, 0) silent data corruption
**Fix applied:** `COALESCE("OwnerId", 0)` removed from the `INSERT INTO Teams_new` statement. `"OwnerId"` is selected directly — any team with a NULL OwnerId will now hard-fail the NOT NULL constraint on `Teams_new`, making the problem visible rather than silently inserting a dangling FK row.

### [MEDIUM — RESOLVED] Router guard passes through on cold load
**Fix applied:** `router.beforeEach` is now `async`. On every navigation, if `!authStore.loaded`, the guard awaits `authStore.fetchMe()` before evaluating redirect conditions. The `authStore.loaded` guards on the redirect conditions were also removed (now always evaluated after load is guaranteed), making the logic cleaner:
```typescript
if (to.name === 'welcome' && authStore.isSignedIn) { return { name: 'teams' } }
if (to.meta.requiresAuth && !authStore.isSignedIn) { return { name: 'welcome' } }
```
